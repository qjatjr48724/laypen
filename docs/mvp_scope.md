# Laypen MVP 범위

- 문서 버전: 0.1
- 상태: 확정
- 기준일: 2026-10-16
- 관련: [제안서](ipad_overlay_handwriting_app_proposal.md), [오버레이 검증](overlay_feasibility_verification.md)

---

## 1. 한 줄 정의

시스템 스크린샷을 **공유로 Laypen에 열어** Apple Pencil로 필기하는 iPad 앱. 계정 없음. 시스템 전역 오버레이는 포함하지 않는다.

---

## 2. 사용자 흐름

```text
다른 앱에서 시스템 스크린샷
  → 썸네일 → 공유 → Laypen
  → 필기 (펜/형광펜/지우개) + ON/OFF
  → (선택) 저장·복원된 현재 작업으로 이어서 작업
```

보조: 메인 앱 실행 → 앨범/최근 스크린샷 선택 → 동일 필기 화면.

---

## 3. MVP In

| 영역 | 내용 |
|---|---|
| 진입 | Share Extension으로 이미지(스크린샷) 수신 → 필기 화면 |
| 보조 진입 | 메인 앱에서 최근/앨범 스크린샷 선택 |
| 도구 | 검정 펜, 컬러 펜, 형광펜, 지우개 |
| 설정 | 도구별 색·굵기 독립 유지 (팔레트/수치는 임시 기본값 OK) |
| 입력 | Pencil만 필기, 손가락은 UI |
| 상태 | 도구 토글 UI + ON/OFF (**OFF = 입력 차단, 획 유지**) |
| 편집 | Undo/Redo, 전체 삭제(확인) |
| 계정 | 없음 |
| 저장 | 현재 작업 로컬 자동 저장·다음 실행 복원 |

---

## 4. MVP Out

- 시스템 전역 투명 오버레이
- PiP 플로팅 필기 (1차)
- 제어 센터에서 다른 앱 화면 캡처
- 백그라운드 스크린샷 자동 감지·자동 수집
- 단축어 자동화 (문서로 권장 안내만 가능, 코드 필수 아님)
- 다중 페이지 / 앱별 공간 / 계정·동기화
- 이미지 보내기 고도화

---

## 5. 아키텍처 의도

| 모듈 | 역할 |
|---|---|
| `BackgroundSource` | MVP: 스크린샷/공유 이미지. 이후 오버레이 가능 시 교체 |
| `StrokeStore` | 획·Undo/Redo·저장 |
| `ToolSettings` | 도구별 색·굵기 |
| `Laypen` | 메인 앱 UI |
| `LaypenShare` | Share Extension 진입 |

필기 렌더링은 PencilKit(`PKCanvasView`)을 우선한다.

---

## 6. 완료 기준

1. 스크린샷 공유로 Laypen 필기 화면이 열린다.
2. 네 도구 + 도구별 설정 유지 + Pencil/손가락 분리가 동작한다.
3. ON/OFF가 획을 지우지 않고 입력만 막는다.
4. Undo/Redo·전체 삭제가 동작한다.
5. 문서에 “오버레이 불가 → 공유 마크업 채택”이 명시되어 있다.

---

## 7. 권장(비필수) 단축 팁

사용자가 원하면 iOS 단축어에서 “스크린샷 촬영 시 → Laypen 열기”를 설정해 진입을 더 줄일 수 있다. MVP 구현 범위에는 포함하지 않는다.
